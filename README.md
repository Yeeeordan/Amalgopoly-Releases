# Amalgopoly

A 2D property-trading board game that mixes rules from many editions into one big game.

## ▶ Play in your browser

**https://yeeeordan.github.io/Amalgopoly-Releases/**

Nothing to install. Use a desktop browser (Chrome, Edge or Firefox). The first load downloads the game, so it can take a moment.

## About this repository

This repository only hosts the playable builds. The game is in active development, so expect frequent updates. The in-game changelog lists what changed in each version.

Current version: **v0.58.0**
